# Typography
## When to use
Use when establishing type roles, hierarchy, rhythm, and constraints for a visual system.
## Required inputs
Creative direction, content hierarchy, language needs, and target formats.
## Step sequence
1. Define text roles. 2. Set relative scale and spacing. 3. Check multilingual and small-size readability. 4. Document fallback behavior.
## Design heuristics
Hierarchy should be visible before reading; expressive choices must not erase legibility.
## Constraints
Respect licensed font availability and platform rendering constraints.
## Verification checklist
Check hierarchy, line length, contrast, density, localization, and fallback behavior.
## Failure modes
Too many type styles, weak hierarchy, decorative overuse, and inaccessible sizes.
## Examples
Synthetic example: a fictional gallery uses one restrained grotesk family with dramatic scale changes instead of multiple display faces.
## What not to do
Do not select a font solely because it resembles a competitor’s identity.
