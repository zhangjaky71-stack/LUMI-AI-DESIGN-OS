# Image Generation
## When to use
Use when the deliverable needs newly generated imagery rather than an edit of an existing source.
## Required inputs
Creative direction, subject, composition, format, reference assets, and fixed constraints.
## Step sequence
1. Separate content from style constraints. 2. Translate direction into generation parameters. 3. Bind approved references. 4. Generate bounded variants. 5. Evaluate against the brief.
## Design heuristics
Describe visual relationships and materials precisely; vary only dimensions that help decision-making.
## Constraints
Do not request protected brand imitation or assume an external image grants reuse rights.
## Verification checklist
Check subject fidelity, composition, artifacts, text expectations, references, dimensions, and brief constraints.
## Failure modes
Prompt drift, uncontrolled variants, invented logos/text, and using generation to bypass asset restrictions.
## Examples
Synthetic example: generate an original studio scene for a fictional skincare bottle using soft side light and a mineral surface, without copying any campaign.
## What not to do
Do not ask for a near-duplicate of a supplied third-party artwork.
