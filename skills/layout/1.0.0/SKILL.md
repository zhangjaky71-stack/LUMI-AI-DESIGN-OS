# Layout
## When to use
Use when converting creative direction and typography into a concrete composition system.
## Required inputs
Typography roles, content priority, format dimensions, and fixed placement constraints.
## Step sequence
1. Establish grid and margins. 2. Place dominant hierarchy. 3. Define spacing rhythm. 4. Test dense and sparse content. 5. Document controlled variations.
## Design heuristics
Use fewer strong alignment rules and meaningful negative space rather than decorative complexity.
## Constraints
Honor fixed safe areas, required content, and responsive bounds.
## Verification checklist
Check reading order, alignment, whitespace, overflow risk, and consistency across target sizes.
## Failure modes
Crowding, accidental symmetry, weak focal point, and layouts that collapse under copy changes.
## Examples
Synthetic example: a poster system uses a stable left anchor and variable image scale while headline and legal zones remain fixed.
## What not to do
Do not solve hierarchy by making every element larger or bolder.
