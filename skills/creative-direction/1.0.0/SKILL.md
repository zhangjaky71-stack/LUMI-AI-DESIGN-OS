# Creative Direction
## When to use
Use after strategy to define the visual logic that downstream design work should follow.
## Required inputs
Brand strategy, available assets, reference evidence, and fixed constraints.
## Step sequence
1. State the central visual idea. 2. Define composition, typography, image, color, and motion principles. 3. Explain reference relevance. 4. Set decision criteria.
## Design heuristics
Prefer one legible concept with controlled variation over a collage of unrelated trends.
## Constraints
Respect user-owned assets and never infer rights from visual similarity.
## Verification checklist
Confirm every principle maps back to strategy and can guide downstream execution.
## Failure modes
Mood without rationale, copied reference structures, and conflicting principles.
## Examples
Synthetic example: “engineered warmth” combines strict grid logic with tactile materials for a fictional hospitality brand.
## What not to do
Do not reproduce a reference image or brand identity as the direction.
