# asset-intelligence

NODE-45 Asset Intelligence V1 provides versioned analysis, OCR/region evidence, multimodal embedding contracts, duplicate tiers, scope-first hybrid retrieval, Agent Asset Resolver, reindex promotion, usage ranking signals, deletion reconciliation and NODE-44 identity evidence adapters.

The core is dependency-free and provider-neutral. Real OCR/VLM/object/embedding models are resolved through NODE-23/Model Gateway adapters; verified binary assets remain owned by NODE-18 Asset Storage.

See `docs/runtime/ASSET-INTELLIGENCE-V1.md` and `reports/nodes/NODE-45/acceptance.md`.
