## Repository-side remediation completed

### 1. Self-contained AWS account bootstrap

`infra/iac/bootstrap/` can now:

- create the account-level GitHub Actions OIDC provider when absent or reuse an explicitly supplied existing provider;
- derive the Terraform state bucket as `lumi-terraform-state-<account-id>-<region>` when no override is provided;
- provision a rotating KMS key and encrypted/versioned S3 Terraform state bucket;
- provision `lumi-staging-github-deploy` and `lumi-production-github-deploy` roles with Environment-scoped OIDC subjects;
- export AWS account, region, state bucket, deploy role ARNs, and up to three available AZs;
- grant explicit ECR repository/push/inspect actions required for Terraform-managed runtime repositories and digest-preserving OCI promotion, without `ecr:*`.

`scripts/aws_release_bootstrap_cloudshell.sh` provides the one-time authenticated AWS CloudShell path. It validates the caller/Region, installs exactly Terraform `1.14.6` after pinned SHA-256 verification, refuses delete/replace bootstrap plans, is plan-only by default, and requires `LUMI_BOOTSTRAP_APPLY=APPLY_AWS_BOOTSTRAP` for mutation. It does not deploy Staging/Production application resources and does not write GitHub variables/secrets.

Bootstrap blocker/handoff issue: `#143`.

### 2. Operation-aware Staging Environment preflight

The canonical Staging deploy workflow now executes `scripts/validate_staging_environment_preflight.py` **before** `aws-actions/configure-aws-credentials`.

The preflight:

- validates only the values needed by the selected operation;
- keeps `plan-core` independent of later App-only DNS/provider/media inputs;
- writes `reports/staging-operations/runtime/environment-preflight.json` with status, required key names, missing key names, and validation reasons only;
- records no secret values;
- exits fail-closed before AWS OIDC when the environment is incomplete;
- is protected by `scripts/validate_staging_release_ops_contract.py`, which requires preflight-before-OIDC ordering and rejects the stale Redis/RabbitMQ GitHub secret mappings.

Hosted `Staging Release Ops Contract` run `32926106063` passed the new preflight contract, Terraform formatting, and release-root init/validate.
